# ⚡ ISBD Studio AI — Adobe Photoshop UXP Plugin

ISBD Studio v1.00 AI-কে সরাসরি অ্যাডোবি ফটোশপের (Adobe Photoshop v24 - v27+) অভ্যন্তরীণ প্যানেলে ব্যবহার করার জন্য নেটিভ UXP (Unified Extensibility Platform) প্লাগইন।

---

## 🌟 সুবিধাসমূহ (Key Features)

1. **👤 MediaPipe 468-pt ফেস রিটাচ:** ফটোশপের ভেতরে সরাসরি ত্বক স্মুথিং, দাঁত উজ্জ্বলকরণ এবং চোখের মণি হাইলাইট।
2. **✂️ PyMatting আলফা হেয়ার কাটআউট:** উড়ন্ত এলোমেলো চুল এবং কাচের স্বচ্ছতা বজায় রেখে সাব-পিক্সেল আলফা কাটআউট নতুন লেয়ারে ইনজেক্ট করে।
3. **✒️ Bézier পেন-টুল ক্লিপিং পাথ:** রাস্টার মাস্ককে স্বয়ংক্রিয়ভাবে মসৃণ অ্যাঙ্কর পয়েন্ট সহ ফটোশপ পেন-টুল ভেক্টরে রূপান্তর।
4. **🎨 নন-ডেস্ট্রাক্টিভ মাল্টি-লেয়ার PSD:** অরিজিনাল ছবি, রিটাচ লেয়ার ও কাটআউট সাবজেক্ট সহ কমপ্লিট `.PSD` এক্সপোর্ট।
5. **⚡ ওয়ান-ক্লিক স্টুডিও এনহ্যান্স:** ফটোশপ ক্যানভাসের যেকোনো ছবি এক ক্লিকে স্টুডিও কোয়ালিটিতে রূপান্তর।

## 🛠️ ফটোশপে ইনস্টল ও সেটআপ নির্দেশিকা (Installation Guide)

### মেথড ১: Adobe UXP Developer Tool (PDT) দিয়ে (প্রস্তাবিত):
1. **Adobe UXP Developer Tool** ডাউনলোড ও ইনস্টল করুন (Creative Cloud ডেস্কটপ অ্যাপ থেকে বিনামূল্যে পাওয়া যায়)।
2. UXP Developer Tool ওপেন করে **"Add Plugin"** বাটনে ক্লিক করুন।
3. এই ফোল্ডারের `manifest.json` ফাইলটি সিলেক্ট করুন (`/home/imon/isbd_model/photoshop_uxp_plugin/manifest.json` বা এটি আপনার পিসিতে কপি করুন)।
4. অ্যাকশন মেনু থেকে **"Load"** বাটনে ক্লিক করুন।
5. ফটোশপ ওপেন করুন -> মেনু থেকে **Plugins ➔ ISBD Studio AI** ওপেন করুন!

### মেথড ২: লোকাল বা রিমোট কানেক্টিভিটি:
- প্লাগইনের টপবারে **সার্ভার সংযোগ (Host URL)** ফিল্ডে লোকাল পিসির জন্য `http://127.0.0.1:8077` অথবা LAN নেটওয়ার্কের জন্য `http://192.168.0.100:8077` সেট করুন।
- স্ট্যাটাস ব্যাজে **"● সংযুক্ত (8077)"** দেখালে প্লাগইনটি সরাসরি ব্যবহারের জন্য প্রস্তুত!

## 📁 ফাইল আর্কিটেকচার
- `manifest.json` — Adobe UXP Manifest v5 কনফিগারেশন
- `index.html` — ডার্ক/লাইট ফটোশপ কমপ্লায়েন্ট UI লেআউট
- `index.js` — ফটোশপ DOM API ও লোকাল ISBD FastAPI সংযোগ স্ক্রিপ্ট
- `styles.css` — অ্যাডোবি স্পেকট্রাম ডার্ক থিম স্টাইলিং
